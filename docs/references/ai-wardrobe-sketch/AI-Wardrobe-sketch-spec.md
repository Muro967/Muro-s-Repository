# AI Wardrobe（AI衣橱）草图设计说明 · 给 AI 阅读版

> 本文档完整描述可点击草图 `ai-wardrobe-sketch.html`（同目录）的界面、交互、数据和视觉规范，目的是让另一个 AI 不看草图也能理解并实现这个 App。
> 截图在 `screens/` 文件夹，文件名与下文「页面清单」编号一一对应。
> 草图版本：2026-10-12（v7）。最后一节列出草图之后确定、但尚未画进草图的产品方向。

---

## 0. 背景速览

| 项 | 内容 |
|---|---|
| 产品 | 个人 AI 衣橱 iOS App：录入衣物 → AI 按天气、场景和个人风格搭配 → 确认穿着 → 统计闲置 |
| 用户 | 一位住在中国大陆的女生（开发者 Muro 的同学），后续可能给几位朋友使用 |
| 平台 | iOS 17+，SwiftUI + SwiftData（可接 iCloud/CloudKit 同步） |
| AI | 通义千问（阿里云百炼，OpenAI 兼容接口），看图模型做识别，文本模型做搭配；提供方可替换 |
| 抠图 | 苹果 Vision 前景实例分割，在手机上完成，目标 2 秒内 |
| 品牌 | 英文名 **AI Wardrobe**，标语 **穿你所有，爱你所穿** |
| 语言 | 界面为简体中文；英文仅用于品牌名、Look 编号和月份等装饰性标题 |

### 硬性产品规则
1. 搭配和配饰**只能使用她衣橱里已有的单品**，AI 返回的每个单品编号都要校验确实存在。
2. 灵感图只能通过拍照、相册或粘贴截图添加，**不做**小红书/Instagram 等平台导入。
3. 超过 **90 天**未穿的单品自动归为闲置；放入「观察中」后有 **30 天**观察期，期内穿一次就移出。两个天数都可在设置里修改。
4. 每套 Look 都带两个标签：**场景 · 风格**（例如「通勤 · 法式」）。
5. 发型建议依据设置里的「发长与发质」（示例：中长发 · 偏直），并附一个短发替代方案。

### 1.2 字体
- **英文装饰标题**：Cormorant Garamond，斜体 500/600。用于品牌名、大数字（48、12%）、温度、Look 编号、月份（September）。
- **中文标题**：Noto Serif SC（思源宋体）600。用于页面标题、区块标题、分类名。
- **正文**：Noto Sans SC（思源黑体）400/500/700；iOS 上可用苹方替代。
- 字号：页面标题 22，区块标题 17，正文 14，说明 12–13，标签 11。

### 1.3 形状与组件
- 大圆角：卡片 22–26，单品卡 18，图片区 12–14，胶囊 999。
- 几乎不用描边，靠浅底色区分层级；阴影很轻，只用在悬浮按钮、Tab 栏和底部弹层。
- **主按钮**：高 46，圆角 23，`--sage-d` 底白字。**次按钮**：`--oat` 底。
- **Chip（筛选胶囊）**：默认 `--card` 底灰字；选中为 `--sage-d` 底白字。
- **分段控件**：`--oat` 底，选中项为白色卡片。
- **AI 角标**：一个小「AI」字样（10px，雾蓝底），标在所有由 AI 自动填写的字段旁。
- **Tab 栏**：悬浮胶囊，距底 22，高 64，半透明白加模糊，共 4 个 Tab：衣橱 / 搭配 / 灵感 / 我的。选中项为主色，下方有小圆点。二级页面隐藏 Tab 栏。
- **悬浮「＋」按钮**：只在衣橱首页出现，位于右下、Tab 栏上方，直径 58，主色。
- **底部弹层（Sheet）**：白底，顶部圆角 26，后面有 25% 深色遮罩；点遮罩关闭。
- 衣物图在草图里是带明暗的矢量插画占位。**真实 App 中显示用户自己拍摄并抠图的照片（透明背景 PNG）。**

### 1.4 页头（所有一级页面通用）
左侧是品牌名「AI *Wardrobe*」（斜体，*Wardrobe* 用陶土色），下方一行小字「穿你所有，爱你所穿」（宋体，字距加宽）。
只有在**衣橱首页**，右上角才有两个圆形图标按钮：左边是**闲置**（收纳盒图标，带粉色数字角标，示例为 6），右边是**搜索**（放大镜）。

## 3. 页面清单

### 01 衣橱首页 `ward`（截图 01、02、03）
从上到下：
1. 页头，右侧有闲置和搜索两个图标。
2. 一行：左边「主卧衣柜 ▾」，点击切换衣柜；右边小按钮「衣柜与分区 ›」。
3. 三格统计卡：**48** 件单品 · **18** 本月穿着天数 · **12%** 闲置率。
4. 区块标题行「**分类 · 风格**」：可以切换分组方式，选中的那个是深色，另一个浅灰。右侧有「管理」。
5. **文件夹卡片**横向滚动。每张卡是带标签页凸起的彩色文件夹，里面扇形叠放 3 张单品缩略图，下面写名称和件数。最后一张是虚线的「＋ 新建分类」（风格模式下是「＋ 添加风格」）。
   - 分类模式：全部 / 上装 / 下装 / 外套 / 连衣裙 / 鞋履 / 包袋 / 配饰。
   - 风格模式：全部 / 法式 / 极简 / 日杂·森系 / 英伦 / 温柔知性 / 度假风 / 美式休闲。
6. 选中「配饰」时，会多出一行子类 Chip：全部、项链、耳环、发饰、帽子、围巾、手表、戒指、手链、胸针、腰带、眼镜（截图 03）。
7. 标题「全部单品」或当前分类名，右侧注明「按最近穿着排序」。
8. **3 列单品网格**。每格依次是：抠图（彩色底）、名称、「穿过 N 次 · 最后穿着时间」，最下面一行用主色小字写位置，例如「主卧 · 短挂区」。
9. 悬浮「＋」进入拍照录入。

### 02 衣柜与分区 `cabinet`（截图 04、05）
- 返回「衣橱」。标题「衣柜与分区」，副标题「点分区查看里面的衣服，可以改名、增删分区」。
- **衣柜 Tab** 横向滚动：主卧衣柜（32 件 · 7 个分区）、次卧衣柜（11 件 · 4 个分区）、换季收纳箱（5 件 · 2 个分区）、虚线「＋ 新建衣柜」。
- **衣柜正视图**：木色外框，内部用网格划分分区，每个分区是一个可点击的格子。
  - 挂衣区：有一根挂杆，下面挂着 2–3 件衣服的小图。
  - 抽屉：中间画一个拉手。
  - 层板：普通格子。
  - 每个格子显示分区名和件数；选中的格子有主色内描边。
- 示例布局（3 列 × 4 行）：顶柜·换季、短挂区、长挂区、叠放层 上、叠放层 下、抽屉、鞋层。
- 两个按钮：「编辑分区」（编辑态下按钮变成「完成编辑」，每个格子出现「✎ 改名」，并显示说明：点名字改名、拖动边线调整大小、长按删除，删除时要选择衣物移到哪里）和「＋ 添加分区」。
- 下方标题「主卧衣柜 › 短挂区」，列出该分区的单品行（缩略图、名称、「分类 · 穿过 N 次」），每行右侧有「移动」按钮。分区为空时显示「这个分区还是空的，录入衣物时选择放在这里」。
- **移动弹层**（截图 05）：标题「移动「燕麦针织开衫」」，副标题写当前位置。先选衣柜（Chip），再选分区（Chip），主按钮显示「移到 主卧衣柜 › 长挂区」；未选分区时按钮禁用，文字为「先选一个分区」。

### 03 拍照录入结果 `capture`（截图 06）
- 返回「衣橱」。标题「识别完成」，副标题「确认信息后保存到衣橱，不对的地方点一下就能改」。
- 正方形抠图预览，透明棋盘格背景，左上角显示「抠图 **1.2 秒**」。
- 信息卡，每行可点击修改，带 AI 角标的是 AI 自动填写的：
  - 分类：外套 › 风衣（AI）
  - 颜色：3 个色点，主色和辅色（AI）
  - 颜色名：焦糖 / 深咖 / 米白
  - 放在哪里：主卧衣柜 › 长挂区
  - 风格：法式、英伦（AI）
  - 季节：春、秋
  - 品牌 / 备注：选填
- 底部按钮：「再拍一件」（次按钮）和「保存到衣橱」（主按钮）。
- 实现提示：抠图和取色在手机上 2 秒内完成；分类、风格等由 AI 异步补全，不阻塞保存。

### 04 搜索 `search`（截图 07）
- 搜索框占位文字「搜名称、颜色、分类、衣柜位置」，边输入边筛选。
- 没有输入时显示「最近搜索」Chip：风衣、阔腿裤、白、主卧 长挂区。
- 筛选项都可多次点击，再点一次取消：
  - 分类 Chip
  - 颜色圆点：白、米、蓝、绿、粉、咖、黑
  - 风格 Chip
  - 季节和场景 Chip
- 结果标题「找到 N 件」，旁边有「清除」；结果用 3 列网格，显示位置。没有结果时提示「没有找到，换个词试试，比如"衬衫"或"米色"」。

### 05 闲置衣物 `idle`（截图 08、09、10）
- 返回「衣橱」。标题「闲置衣物」，副标题「超过 90 天没穿会自动归入，数据来自每天确认的穿搭」。
- 两张环形进度卡：**闲置率 12%**（豆沙色）和 **处置率 29%**（灰绿色）。处置率 = 已处置 ÷（已处置 + 全部闲置）。
- 分段控件：**全部闲置 3 / 观察中 2 / 已处置 2**。
- 列表行：缩略图、名称、说明（如「142 天未穿 · 入库 2025-03」）。
  - 全部闲置：每行有「观察」和「处置」两个按钮。点「观察」后移入观察中，显示「观察剩余 30 天」。
  - 观察中：每行有「处置」按钮。
  - 已处置：顶部有汇总卡，列出各处置方式的件数和二手收入合计（示例 ¥180）；每行写方式、金额、平台和日期。
- **处置弹层**（截图 09）：标题「处置「奶油色连衣裙」」，用 2 列卡片选择方式：
  - 二手卖出（记录售价和平台）：额外显示售价输入框和平台 Chip（闲鱼 / 转转 / 线下）
  - 送给朋友（记下送给谁）：额外显示「送给谁」输入框
  - 捐赠（公益机构或旧衣箱）
  - 旧衣回收（回收点或上门回收）
  - 改造（改成别的单品）
  - 丢弃（破损无法再穿）
  - 处置日期：「今天」或「选择日期」。
  - 主按钮显示「确认：二手卖出」；未选方式时禁用。确认后单品移到「已处置」。

### 06 搭配 `look`（Tab 2，截图 11、12、13）
1. 页头。
2. **天气卡**：雾蓝到燕麦色渐变，显示定位「上海 · 静安」、大号温度 18°，以及「多云 · 14°–21° · 降水 20% · 午后有风」。
3. 「今天去哪儿」场景 Chip：通勤 / 休闲 / 运动 / 派对 / 正式 / 度假，单选。
4. 标题「为你搭了 3 套」，小字「点单品可替换」，右侧有「换一批」。
5. **Look 卡片横向轮播**（宽 286，左右滑动，下方有指示点）。每张卡依次包含：
   - 头部：左边「*Look 01*」（斜体），右边两个标签「通勤」「法式」，风格标签用浅粉底。
   - **平铺图**：彩色底板上摆放 3–4 件单品抠图（上衣、下装、外套、鞋或包）。点任一件会在底板下方弹出「替换「白色亚麻衬衫」」面板，列出 4 件同类候选（截图 12）。
   - **配饰行**：「配饰」后面跟 2–3 个小方块配饰图，再接配饰名称，例如「金色锁骨链 · 棕色皮带手表」。
   - **发型建议框**（浅粉底，带头像图标）：「发型建议 · 低盘发」，下面一行说明「风大也不乱，露出风衣领口和锁骨链」，再一行短发替代「短发可选：自然侧分，发尾略蓬」。
   - **推荐理由**：一句话结合天气和闲置情况，例如「最高 21°，早晚 14° 有风，叠一件风衣，傍晚降温也够。」
   - 按钮：「✓ 今天穿这套」（主按钮）和 ♡ 收藏（可切换，收藏后为粉底 ♥）。
6. 点「今天穿这套」后出现确认条：「已记录今天的穿搭 · 4 件单品穿着次数 +1」，右侧有「拍一张」，用来拍当天穿搭照，月报里会用到人像抠图。
7. 「我的搭配」区块：标题右侧「全部 N 套 ›」进入历史页；分段「已穿记录 / 收藏」；下面是 2 列卡片，最多 4 张。

### 08 灵感 `insp`（Tab 3，截图 15、16）

2. **我的风格画像**卡（右上角注明「基于 23 张灵感图」）：

   - 东方（传统元素的现代穿法）：新中式、和风、民族风

5. 「灵感墙」：2 列瀑布流的人物穿搭图，每张下面有 AI 风格标签。

## 4. 交互要点（来自草图脚本）
- 一级页面通过 4 个 Tab 切换；二级页面左上角有「‹ 上一级」返回，并隐藏 Tab 栏。
- 衣橱首页：切换「分类 / 风格」会重置为「全部」；点文件夹即筛选；选中「配饰」时出现子类 Chip。
- 搭配页：切换场景会清除「已确认」状态；轮播滑动时同步更新指示点；点单品打开或关闭替换面板；「换一批」轮换方案。
- 收藏 ♡ 可以切换，结果实时反映到「我的搭配 · 收藏」。
- 确认穿着后，这套搭配加入「已穿记录」，单品的穿着次数 +1。在真实 App 中，这还会更新「最后穿着日」，进而影响闲置计算。
- 闲置：全部闲置 → 观察（30 天）→ 处置（选方式）→ 已处置。处置率实时重新计算。
- 移动单品：选衣柜 → 选分区 → 确认，单品的位置字段随之更新。

## 6. 草图之后确定的产品方向（尚未画进草图，实现时以此为准）

2026-10-13 与 Muro 讨论后确定：**核心卖点是「按她喜欢的风格、只用她已有的衣服」生成搭配**。柜子分区、闲置、月报属于锦上添花，可以往后放。

1. **风格说明书**：从灵感图提炼出具体规则，例如偏爱的色系、廓形、常用组合，以及「不喜欢」清单（亮色大面积、紧身、豹纹等）。她可以直接查看和修改。「不喜欢」是 AI 必须遵守的硬性规则。
2. **用我的衣服复刻这张图**：在任意灵感图上，AI 从她的衣橱里挑出最接近的一套，说明哪里像，并指出缺哪件。这需要一个新入口：灵感图详情页上的「复刻」按钮，以及对应的结果页。
3. **每套推荐注明参考了哪张灵感图**，让推荐有依据。
4. **单品描述要细**：版型、长度、材质、正式程度。AI 自动填写，她可以修改，因为 AI 只读文字描述。
5. **先多生成再筛**：先生成 6–8 套，用规则检查颜色冲突和正式程度，再让 AI 按风格说明书打分，只留最像她的 3 套。
6. **反馈学习**：每套可以点喜欢或不喜欢；不喜欢时可选原因（太正式 / 颜色不搭 / 不像我）。换掉的单品和最终穿了哪套都会记录下来，用来更新说明书，并作为下次生成的示例。同时统计采纳率。
7. **设置里加「导出备份」**。

**开发与分发**：先用免费 Apple ID 从 Mac 用 Xcode 装到自己的 iPhone 试用（每 7 天重新运行一次；不删 App 数据就不会丢）。给同学和朋友用时再开通开发者账号，用 TestFlight 分发。多人使用时，通过一个小后台中转 AI 请求（Key 放在服务器上，用邀请码激活，按人限额）。
